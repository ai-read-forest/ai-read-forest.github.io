03

새소리를 분석하는 세 단계

첫 고리인 "듣고 종을 알아내기"를 BirdNET이 한다. 같은 원리로 내 목소리도 분류해 본다.

새소리 데모는 실제 BirdNET V2.4의 출력을, 내 목소리는 우리가 만든 작은 남/여 목소리 모델의 출력을 보여 준다(Kahl 외, 2021).

실제 계산BirdNET 출력설명용 그림

← → 또는 Space로 넘기고, F로 전체 화면. 휴대폰은 좌우로 밀어 넘긴다.

1단계 소리 → 그림

녹음

실제 계산

BirdNET은 소리를 3초씩 듣는다. 내 목소리를 3초 녹음하거나, 국민대에서 녹음한 직박구리 소리를 골라 보자.

녹음은 이 브라우저 밖으로 나가지 않는다.

실제 계산

소리는 1초에 48,000번 잰 숫자로 저장된다. 3초면 144,000개, 이어 그리면 파형이다.

실제 계산

짧은 조각 하나를 떼어 FFT로 어떤 높이의 소리가 섞였는지 나눈다. 그 결과가 그림의 세로 한 줄이 된다.

조금 더

21 ms 조각에 Hann 창을 곱하고 FFT를 한 뒤, mel 필터 96개로 묶는다. 낮은 소리는 촘촘하게, 높은 소리는 넓게 묶는다.

실제 계산

한 줄씩 옆으로 이어 붙이면 스펙트로그램이다. 가로는 시간, 세로는 높낮이, 진할수록 센 소리다.

목소리는 BirdNET의 저음용 그림(0–3 kHz)으로 본다.

조금 더

BirdNET V2.4는 같은 3초로 고음용(0.5–15 kHz)과 저음용(0–3 kHz) 두 장을 만든다. 이 페이지는 같은 설정으로 그리되, 모델 내부와 달리 교과서식 세기(|X|²)를 쓴다.

실제 계산예시 필터

작은 창(필터)이 그림 위를 지나가며 닮은 무늬를 찾는다. 여기 필터는 설명용 예시다.

작은 창(필터)이 그림 위를 지나가며 무늬를 찾는다. 이 필터는 목소리 모델이 학습한 실제 필터다.

설명용 그림BirdNET 출력실제 계산

층을 거듭할수록 그림은 작아지고, 마지막에 숫자 1,024개짜리 벡터가 남는다. 3초 소리의 요약이다.

층을 거듭할수록 그림은 작아지고, 목소리 모델은 숫자 32개짜리 벡터로 요약한다.

BirdNET 출력실제 계산

벡터에서 종마다 숫자 하나를 내고, sigmoid로 0–1 신뢰도 점수로 바꾼다. 종마다 따로 계산해서 합이 1이 아니다.

벡터에서 숫자 하나를 내고 sigmoid로 0–1 점수로 바꾼다. 1에 가까울수록 남성 목소리 쪽이다.

BirdNET 출력실제 계산

기준 점수를 넘은 종을 기록한다. 점수는 맞을 확률이 아니다(Symes 외, 2024).

목소리 높낮이 같은 특징으로 추정한 것이라 틀릴 수 있다. 영어 낭독 음성으로 학습했고 한국어 목소리로는 시험하지 않았다.
